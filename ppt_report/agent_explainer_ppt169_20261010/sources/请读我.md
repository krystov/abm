复现论文《Beyond innovation and deployment: Modeling the impact of technology-push
and demand-pull policies in Germany's solar policy mix》的 ABM 模型（德国光伏政策组合
多主体模型），并用 LLM Agent 增强主体决策能力。两条主线：

  1. 模型复现（论文 SI 的 Adopter/Manufacturer/Installer + 5 步调度 + 两阶段采用
     （ideation 阈值 + NPV 双选）+ 双因子经验曲线 + 劳动力市场 + 宏观环境 + 历史数据）
  2. LLM Agent 接入（Manufacturer/Adopter 接 LLM，ConversationMemory + tool calling +
     Pydantic 校验 + 异步并发 + 确定性回退）
