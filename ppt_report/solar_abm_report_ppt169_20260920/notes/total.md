# 01_cover

这次汇报的主题是把一篇关于德国光伏政策组合的论文用代码复现出来，并在此基础上让大语言模型参与主体决策。项目有两条并列的主线：模型复现完成度大约九成五，LLM 增强大约七成五。封面右侧这三个数字是今天最希望大家记住的：五百个采用者样本里有五十个最终安装，累计装机零点六兆瓦，国内组件成本二十六年下降了百分之八十五点九。最后一个数字留个伏笔——真实采用率大约是百分之七，我们跑出来是百分之十，这个偏差后面会专门讲。

# 03_background

论文问的是一个很具体的问题：技术推动，也就是政府研发投入，和需求拉动，也就是上网电价补贴，这两类政策如何共同塑造德国光伏从一九九一年到二零一六年的扩散轨迹。我们的工作分两层。第一层是复现：把论文补充材料里的多主体模型完整重建，包括三类主体和一个宏观观察者，时间跨度三百一十二个月，所有关键参数都按补充材料的参数表逐项对齐。第二层是增量：让制造商与采用者的决策改由大语言模型完成，带上对话记忆、工具调用和结构化校验，一旦失败就自动回退到公式，保证仿真不会中断。这两条线的完成度分别是九成五和七成五。

---

# 04_architecture

整个系统有四类角色。最上面是宏观环境，它每个月提供五组外生信号：电价、上网电价补贴、媒体关注度、研发强度，以及全球累计装机。下面三类是主体。采用者共五百个，按真实人口千分之一缩比，其中住宅占百分之八十一，工商业占百分之十八点五，电站占百分之零点五。安装商和制造商各有国内与国外两个。采用者产生的新需求先进入安装队列，安装商按产能消化订单并把成本与价格反馈回去，制造商在当月销量结算之后更新成本。此外，国内与国外制造商之间会按知识差距比例互相溢出学习，而采用决策和实际安装之间隔着队列，因此存在时滞。

---

# 05_schedule

每个 tick 等于一个月，五个步骤的顺序是固定的，不能颠倒。第一步更新宏观变量，读取当月的外部信号。第二步采用者决策：没有安装的主体评估本月是否安装，产生的新需求进入待安装队列。第三步安装商响应，按产能消化订单，同时调整用工和非组件成本报价。第四步制造商更新：结算累计产量、更新知识存量，并按经验曲线调整成本。第五步记录装机量、就业与价格，时钟推进到下个月。从一九九一年到二零一六年，一共是三百一十二个 tick，这套顺序对应论文补充材料的第一点一点五节。

---

# 06_adoption

采用不是一个公式算出来的，而是两阶段。阶段一叫萌生念头：主体把四个变量加权求和，超过零点五才会进入下一步。这四个变量是邻居已装比例、当月信息量、环境意识和代表家庭的内部收益率，权重分别是零点一九、零点一七、零点五二和零点一二，其中环境意识权重最高。阶段二才做经济评估。环境意识高于零点九二并且是住宅用户的主体属于早期采用者，直接安装，跳过经济账。其余主体分别计算国内和国外组件的净现值，只有在最大值非负时才安装，平局时偏好国内。国外组件还额外承受百分之一点一的折现溢价。

---

# 07_experience_curve

组件成本的下降由两个独立驱动共同决定，这是论文里很重要的一点。干中学指累计产量越高、成本越低；研究中学指知识存量越多、成本越低，知识存量按永续盘存的方式更新，每月折旧约零点八七四，相当于每年百分之十。参数全部对齐论文的参数表：截距在国内、国外和非组件分别是二点八八二、二点四四八和三点三五四；干中学斜率国内是负零点零七四，国外是负零点四四八，也就是说国外更依赖规模；研究中学斜率国内是负零点八一四，国外是负零点零七四，也就是国内更依赖研发。这组不对称的参数，正是后面两条成本曲线分岔的原因。

---

# 08_labor_market

安装商在模型里不只是执行末端，它同时是缓冲器和降温阀。采用决策先进入待安装队列，再由安装商按产能逐月消化，所以决定安装和实际安装之间存在时滞。如果积压超过阈值就招人，低于阈值就裁员，并且有就业下限。人手不足时，安装商会提高非组件成本报价，成本上升又会拖慢安装速度，于是形成一个自我降温的负反馈回路。非组件成本本身走单因子经验曲线，斜率是负零点一五五，对应百分之十点二的学习率。这三条机制共同让市场不会无限过热。

---

# 09_llm_agents

LLM 只接管两类主体的决策。制造商每个月决策一次，两个厂商各一次，输出产能动作、变动幅度和研发方向，结果必须通过数据校验才会执行。采用者则是每个月从未决策的人群里随机抽取百分之五，判断本月是否安装，并给出置信度和主因。它们共享同一套能力：滚动六轮对话记忆，可以调用工具查询市场行情、邻居采用率、静态回收期和自身产能库存，并发发起请求，最多进行三轮工具循环。最关键的是回退链：网络错误、返回内容不是合法 JSON、或者校验不通过，制造商会退回经验曲线公式，采用者会退回两阶段公式，仿真不会中断。模型提供方用的是 DeepSeek 的兼容端点。

# 10_results

这张四联图是公式模式三百一十二个 tick、随机种子四十二、合成数据下的结果。左上角累计装机呈 S 形：二零零零年之前几乎贴地，二零零四到二零零八年最陡，之后走平，终点是零点六兆瓦。右上角是组件成本，国内下降百分之八十五点九，国外下降百分之九十六点六，二零零零年之后两条线迅速拉开。左下角累计采用者同样呈 S 形，最终是五十比五百。右下角是政策信号：上网电价补贴二零零零年上线，二零零四到二零零八年达到高峰，此后持续退坡。把四张图连起来看，结论很清楚：采纳是被政策点燃的，不是自发的——一九九一到一九九九年完全没有补贴，只有六户环境意识极高的住宅用户安装。

# 11_key_numbers

这一页把可以核对的数字集中放出来。累计采用五十户，也就是百分之十；累计装机零点六兆瓦；国内组件成本下降百分之八十五点九；单元测试九十三个全部通过。下面的年度检查点可以逐点核对：一九九一年六户，二零零零年八户，二零零四年二十二户，二零零八年五十户，之后到二零一六年保持在五十户，说明二零零八年以后模型里不再有新增。右下角这条曲线就是这条轨迹的可视化。需要提醒的是，真实德国住宅光伏采用率大约是百分之七，我们跑出来百分之十，偏差大约三个百分点，原因在下一页。另外，公式模式跑完整个周期只需要十二到十五秒，LLM 模式则受接口速率限制，需要节流。

# 12_gaps

现在讲两处偏差，它们是已知而且已经定位的，不是没发现的问题。第一处是采用率偏高：模型给出百分之十，真实大约百分之七。根因是邻居半径用了十公里，而论文是一公里。这么改是为了补偿五百个主体的缩比——如果按一公里算，平均只有零点一六个邻居，社会影响根本启动不起来。修法是接入空间索引、把主体扩到两万，再改回一公里并重新标定。第二处是国外成本塌缩：模型给出零点零八四欧元每瓦，真实大约零点三。根因是学习驱动量用了全球累计装机，而不是论文要求的本区域累计产量，同时合成数据里的全球装机量级膨胀了大约十倍，再被国外陡峭的干中学斜率放大。修法是修正全球装机量级，并为国外厂商引入外生的区域产量序列。还要说明一点：如果字面上改回自产累计产量，结果会反向失真，国外变成二点二四、国内变成零点七六一，这个取舍记录在测试记录第十三轮。

当前的状态可以这样概括：复现这条主线已经可以依赖，LLM 这条主线可用，但覆盖范围仍然有限。复现部分完成度大约九成五，主体定义、五步调度、两阶段采用、经验曲线、劳动力市场、宏观与历史数据、以及分析可视化全部落地。LLM 部分大约七成五，接线、工具调用、对话记忆、并发、校验和确定性回退都已经工作。验证方面，三百一十二个 tick 的公式模式完整跑通，九十三个单元测试全部通过，耗时不到一秒；DeepSeek 的三项能力也都实测过；之前那个导致全部静默回退的缺陷已经修复，冒烟测试确认零回退。最后提两条代码债：配置中心还没有接入主流程，参数仍硬编码在模型文件里；另有一个早期的单阶段版本模块，现在只有测试还在引用。

# 14_next_steps

下一步有三个候选，我建议先做 A，也就是模型校准。具体是修正全球装机量级和国外学习驱动量，逐图逐表对比论文输出，把采用率拉回到百分之七左右；它的代价最低，却直接决定现有结论是否可信。B 是扩大主体规模，为邻居计算接入空间索引，把主体从五百扩到两万，半径改回一公里，代价中等，好处是消除缩比带来的假象，但需要重新标定。C 是接入成熟的多智能体框架，做多步推理和更复杂的角色协作，代价最高，收益偏探索性。所以建议的顺序是 A、B、C：先让数字可信，再让规模可信，最后才谈能力上限。今天最想和大家达成一致的，就是这个优先级。
